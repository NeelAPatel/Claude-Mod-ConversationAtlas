# Decision records

A `decision-needed` issue closes with an outcome written here, so the reasoning outlives the chat.

One file per decision, named `NNNN-short-title.md` (copy [0000-template.md](0000-template.md)). Numbers only go up; never reuse one.

Each record has:

- **Title**: the question, in a few words.
- **Status**: proposed, accepted, or superseded by NNNN.
- **Context**: what forced the decision and what was considered.
- **Decision**: what was chosen, in one or two sentences.
- **Consequences**: what changes, what it costs, what it rules out.
- **Links**: the GitHub issue(s) (`#n`) and any PR that carried it out.

Keep records short. To change a decision, add a new record and mark the old one superseded.
