# Changelog

Versions follow [semver](https://semver.org). The version lives in `.claude-plugin/plugin.json`
only. Each release is a git tag `vX.Y.Z` on `main`.

## v0.1.0 — first release

- First public release of Conversation Atlas.
- Atlas absorbed Trailhead's intent model (goal, detour, return packet).
- Trailhead checkpoint recovery, labels and wording removed. Atlas save files are the only
  recovery source.
