# Atlas feature map

Use these TUI routes from the repository root. Each feature file gives the full command, expected frame, and Button keys.

| Feature | File | Description | How to reach |
| --- | --- | --- | --- |
| Map | map.md | Goal, path, detour cue, activity, working set, latest items, and next step. | sample; snapshot |
| Trail | trail.md | Topic tree and chronological conversation trail. | sample; tab trail |
| Open | open.md | Suggestions, observed decisions, and unanswered questions. | sample; tab open |
| Evidence | evidence.md | Checkpoints, settled and resolved items, detours, earlier sessions, and files. | sample; tab evidence |
| App bar, Legend, Mark | app-bar-legend.md | Pinned app bar, help notes, Legend, and Mark action. | sample; legend; scroll end |
| Trail Settings popup | trail-settings-popup.md | Three settings pages for Trail view, order, and hidden types. | sample; tab trail; press trail-view-menu; settings-page-next twice |
| Decisions popup | decisions-popup.md | Requested popup name; current decision details expand inline. | sample; tab open; press dsel-d18 |
| Open questions popup | open-questions-popup.md | Requested popup name; current question details expand inline. | sample; tab open; press qsel-q22 |
| Setup consent | setup-consent.md | Observer choice screen shown before setup is recorded. | setup; snapshot |
| Goal | goal.md | Confirmed goal, alternatives, editing state, and goal suggestion. | sample; press goal-row, or nogoal; tab open; press sg-s-no-goal |
| Detour | detour.md | Possible detour, taking it, then returning or promoting it. | sample; press ok-s12; press detour-topic-x42; press return or promote |
| Scrolling | scrolling.md | Pane window movement, scroll controls, and body size redraw. | sample; height 10; snapshot; press scroll-down; scroll 5; size 46x12 |
